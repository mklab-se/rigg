# Getting started

This walkthrough moved into the tutorials, one per situation:

| Start here if you… | Tutorial |
|---|---|
| already have a stack in Azure | [1 — Put an existing Azure solution under version control](docs/tutorials/01-pull-an-existing-solution.md) |
| are starting from an empty storage container | [2 — Build from scratch](docs/tutorials/02-build-from-scratch.md) |
| need a second environment | [3 — Add an environment and promote](docs/tutorials/03-add-an-environment-and-promote.md) |
| are about to touch production | [4 — Push to protected production](docs/tutorials/04-push-to-protected-production.md) |

**Before the first one,** read [CONCEPTS.md](CONCEPTS.md) — or run
`rigg concepts` — for the workspace/project model.

**Then:** [docs/README.md](docs/README.md) is the full documentation index,
and [docs/how-rigg-works.md](docs/how-rigg-works.md) explains what the
commands actually compute.
